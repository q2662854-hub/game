# شیشه‌شکن — Stone the Lux

یه بازی آرکیدِ مرورگری: شب، خیابون‌های شهر، و ماشین‌های لوکس که از افق میان.
با سنگِ آتشین به شیشه‌هاشون بزن تا خرد بشن، از کار بیفتن و از جاده منحرف بشن.

## اجرا
هیچ بیلد یا نصبی لازم نیست:

```bash
python3 -m http.server 8000
# بعد http://localhost:8000 را باز کن
```

## کنترل‌ها
- **کلیک / لمس** یا **Space**: پرتاب سنگ به سمت نشانگر
- نگه‌داشتن و کشیدن موس/انگشت: پرتاب سریع پشت‌سرهم
- **P / Esc**: توقف — **M**: قطع و وصل صدا

## قواعد
- هر ماشین سه شیشه دارد (چپ، وسط، راست) + بدنه. زدن به بدنه فقط جرقه و دندانه می‌دهد.
- زنجیرهٔ ضربه‌ها ضریب امتیاز را تا ×۵ بالا می‌برد؛ بدنه‌زدن یا از دست رفتن ماشین زنجیره را می‌شکند.
- از کار افتادن هر ماشین کمی زمان اضافه می‌کند؛ هر مرحله پاداش و زمان بیشتر می‌دهد.
- ماشین زره‌پوش و پلیس (با آژیر) سخت‌تر ولی پرامتیازترند.
- حرارت دست بالا برود، چند لحظه نمی‌توانی پرتاب کنی.

## ساختار
| فایل | نقش |
|---|---|
| `index.html` | ساختار صفحه، HUD و منوها |
| `css/style.css` | تم شبانه، شیشه‌ای‌ها، واکنش‌گرا |
| `js/utils.js` | ابزارها، اعداد فارسی، رکوردها |
| `js/audio.js` | همهٔ صداها با Web Audio سنتز می‌شوند (بدون فایل صوتی) |
| `js/cars.js` | مدل‌های ماشین، رسم پروسه‌ای و شیشه‌های قابل شکستن |
| `js/game.js` | موتور بازی: جاده، نور، ذرات، برخورد، امتیاز |
| `js/ui.js` | اتصال HUD و صفحه‌ها |
| `js/main.js` | ورودی‌ها، حلقهٔ بازی، شروع/توقف |
