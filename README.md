# 🔥 شیشه‌شکن — Glass Breaker

بازی تحت‌وب آرکید: ماشین‌های لوکس از خیابان رد می‌شوند؛ با **سنگ آتشین** شیشه‌هایشان را بشکن تا از کار بیفتند و از جاده منحرف شوند.

![وضعیت](https://img.shields.io/badge/HTML5-Canvas-orange) ![بدون وابستگی](https://img.shields.io/badge/dependencies-0-success)

## 🎮 نحوه‌ی بازی
- **نشانه بگیر:** ماوس یا انگشت را روی ماشین ببر.
- **نگه دار:** هر چه بیشتر نگه داری، سنگ قوی‌تر پرتاب می‌شود (حلقه‌ی دور سنگ میزان قدرت را نشان می‌دهد).
- **رها کن:** سنگ آتشین پرتاب می‌شود؛ مسیر پیش‌بینی‌شده را با نقطه‌های روشن می‌بینی.
- **هر دو شیشه** یک ماشین را بشکن تا از کار بیفتد و از جاده منحرف شود.
- ۶۰ ثانیه فرصت داری، کمبو بساز و رکورد بزن.

## ✨ امکانات
- ۸ مدل ماشین لوکس (مرسدس بنز، بی‌ام‌و، رولزرویس، پورشه، فراری، لامبورگینی، بنتلی، بوگاتی) — همه با گرافیک برداری و بدون هیچ فایل تصویری
- دو لاین با عمق و مقیاس متفاوت، ترافیک ترتیبی و سختی تدریجی
- سنگ آتشین با دنباله‌ی شعله، ذرات، دود و جرقه
- خردشدن شیشه با ترک، قطعات شیشه و لرزش دوربین
- اسلوموشن + فلاش + شیک هنگام از کار افتادن ماشین
- ماشین **زره‌پوش** (۲ ضربه برای هر شیشه) و ماشین **طلایی** (۲ برابر امتیاز)
- سیستم کمبو ×۵، هود بارگذاری سنگ، شمارش دقت پرتاب و ذخیره‌ی رکورد در `localStorage`
- صداهای ساخته‌شده با WebAudio (بدون فایل صوتی)
- پشتیبانی از ماوس و لمس، طراحی واکنش‌گرا

## 🚀 اجرا
فقط `index.html` را باز کن. برای اجرا از طریق سرور محلی هم می‌توانی:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```

هیچ build و هیچ وابستگی‌ای لازم نیست.

## 📁 ساختار
```
index.html      رابط کاربری، منو، HUD
css/style.css   ظاهر و انیمیشن‌های رابط
js/cars.js      موتور گرافیک برداری ماشین‌ها (بدنه، شیشه، چرخ، چراغ)
js/game.js      حلقه‌ی بازی، فیزیک، برخورد، ذرات، وضعیت‌ها
js/audio.js     افکت‌های صوتی سینتزشده با WebAudio
```

## ⌨️ کلیدها
| کلید | کار |
|---|---|
| کلیک / لمس | نشانه‌گیری و پرتاب |
| `P` یا `Esc` | توقف / ادامه |
| `M` | قطع و وصل صدا |
