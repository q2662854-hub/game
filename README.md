# میز اشرافی · بیلیارد سه‌بعدی ۸ توپ

یک بازی بیلیارد کامل و سه‌بعدی با گرافیک لوکس، رابط فارسی و حریف هوش مصنوعی.
کل بازی در **یک فایل HTML مستقل** بسته‌بندی می‌شود:

```
billiard-3d.html      ← خروجی نهاییِ تک‌فایلی (بدون اینترنت، بدون نصب)
```

## اجرا

فایل `billiard-3d.html` را در مرورگر باز کنید — همین. همه‌چیز (Three.js، استایل‌ها،
فونت وزیرمتن) داخل همان فایل جاسازی شده است.

## ساختِ دوباره

```bash
npm install
npm run build:single   # همان فایل billiard-3d.html را از نو می‌سازد
npm run dev            # اجرای نسخهٔ توسعه با Vite
```

## کنترل‌ها

| عمل | ماوس / کیبورد | لمسی |
|---|---|---|
| نشانه‌گیری | حرکت ماوس | کشیدنِ افقی |
| قدرت ضربه | اسکرول، کلیدهای ↑ ↓، نوار قدرت | کشیدنِ عمودی یا نوار قدرت |
| ضربه | کلیک، `Space` یا دکمهٔ «ضربه» | دکمهٔ «ضربه» |
| چرخش دوربین | دکمهٔ دوربین | دکمهٔ «⋮» |
| توقف | `Esc` | دکمهٔ توقف |

## چه چیزهایی پیاده‌سازی شده است

- **میز واقعی**: ماهوت زمردی با بافت پارچه، ریل چوب‌گردو با روکش لاک،
  بالشتک‌های زاویه‌دار، جیب‌های واقعی با لبِ کروم و شش نشانهٔ الماسی روی ریل.
- **فیزیک بیلیارد**: برخورد الاستیک توپ‌ها، اصطکاک غلتش، برخورد با بالشتک،
  افتادن در جیب، تشخیص خطا (سفید افتاده / برخورد اشتباه / بی‌برخورد).
- **قوانین ۸ توپ**: میز باز تا اولین توپ افتاده، تعیین گروه (تک‌رنگ/راه‌راه)،
  ادامهٔ نوبت پس از پاکت، توپ در دست پس از خطا و شرط برد با توپ ۸.
- **حریف هوش مصنوعی**: مسیر و زاویهٔ برخورد را حساب می‌کند، مانع را تشخیص می‌دهد،
  برای هر توپ بهترین جیب را انتخاب می‌کند و ضربهٔ ایمنی هم می‌زند.
- **رابط کاربری**: پنل شیشه‌ای با حاشیهٔ طلایی، قدرت ضربه با نوار گرادیانی،
  کارتِ نوبت، شمارندهٔ گروه‌ها، پیام‌های شناور، انیمیشن ورود و صفحهٔ نتیجه.
- **صدا**: تمام افکت‌ها (برخورد چوب، توپ، بالشتک، افتادن در جیب، پیروزی) با
  Web Audio سنتز می‌شوند؛ هیچ فایل صوتی خارجی لازم نیست.

## ساختار کد

```
src/pool/
  constants.js    ابعاد میز، جیب‌ها و ثابت‌های فیزیک
  textures.js     بافت‌های تولیدشده با Canvas (ماهوت، چوب، توپ، الماس)
  environment.js  رندرر، دوربین، نورپردازی، بلوم و پس‌پردازش
  table.js        هندسهٔ کامل میز و جیب‌ها
  balls.js        چیدمان راک و متریال رزینی توپ‌ها
  physics.js      شبیه‌سازی و پیش‌بینی مسیر
  cue.js / aim.js چوب بیلیارد و راهنمای نشانه‌گیری
  fx.js           ذرات درخشان
  audio.js        سنتز صدا
  game.js         منطق بازی، قوانین و دوربین
  ui.js / ui.html / ui.css   رابط کاربری فارسی
scripts/build-single.mjs     بسته‌بندی تک‌فایلی
```
