# NEON 2048 — بازی ۲۰۴۸ سه‌بعدی

یک نسخهٔ سه‌بعدی و سینمایی از بازی محبوب ۲۰۴۸، ساخته‌شده با **Three.js**، **Vite** و محاسبات سبک.

## ✨ ویژگی‌ها

- **سه‌بعدی واقعی:** هر بلوک یک مکعب شیشه‌ای/فلزی است با بازتاب محیط، سایه و بلوم.
- **اعداد انگلیسی و خوانا:** بافت عددی با فونت Space Grotesk روی سطح بالا و هر چهار ضلع کناری.
- **جلوه‌های بصری:** شوک‌ویو، جرقه و ذرات، ستون نور برای ادغام‌های بزرگ، ستاره‌ها، سحابی و آینهٔ کف.
- **صداگذاری کامل:** تمام افکت‌ها و موسیقی پس‌زمینه با Web Audio API سنتز می‌شوند (بدون فایل صوتی).
- **حرکت و کنترل:** کیبورد (کلیدهای جهت‌دار + WASD)، سوایپ لمسی و دی‌پد روی موبایل.
- **بازگردانی حرکت (UNDO)**، ثبت رکورد در `localStorage`، صفحهٔ برد با گزینهٔ ادامه.
- **واکنش‌گرا:** چیدمان و دوربین جداگانه برای موبایل، تبلت و دسکتاپ.

## 🎮 اجرا

```bash
npm install
npm run dev      # سرور توسعه روی پورت 5173
npm run build    # خروجی تولید
npm run preview
```

## 🕹️ کنترل‌ها

| عمل | کلید |
| --- | --- |
| حرکت | کلیدهای جهت‌دار / WASD / H J K L / سوایپ |
| بازگردانی | `U` یا `Backspace` |
| بازی جدید | `R` |
| صدا | `M` |
| چرخش صحنه | `V` |
| شروع / ادامه | `Space` |

## 🧱 ساختار پروژه

```
src/
  main.js            کنترلر بازی و رابط کاربری
  style.css          استایل HUD و اسکرین‌ها
  game/
    logic.js         منطق خالص 2048 (بدون وابستگی به رندر)
    tiles.js         رنگ‌ها، سبک بلوک‌ها و مختصات صفحه
    tile.js          ساخت بلوک سه‌بعدی و بافت‌های عددی
    scene.js         صحنه، دوربین، نورپردازی و پست‌پروسسینگ
    fx.js            سیستم ذرات، امواج و جلوه‌های محیطی
    audio.js         موتور صدا و موسیقی سنتزشده
```
